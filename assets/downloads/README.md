## File Naming Convention
- Use lowercase with hyphens: `business-registration-guide.pdf`
- Include version numbers if applicable: `contract-template-v1.0.pdf`
- Keep file names under 50 characters

## Specifications
- **Max file size**: 5MB per document
- **Format**: PDF (optimized), ZIP for bundles
- **Accessibility**: All PDFs should be accessible (tagged, searchable)
