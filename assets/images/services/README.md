This directory contains icons for all 8 service categories offered on Hostara.

## Service Categories

See `/PLACEHOLDERS.md` Section 3 for complete specifications.

8. **service-professional.svg** - Professional Services

## Specifications
- **Format**: SVG (optimized with SVGO)
- **Dimensions**: 128x128px (scalable)
- **Style**: Line icons, 2px stroke weight
- **Color**: Use `currentColor` (styled via CSS)
- **Padding**: 16px internal padding
- **Background**: Transparent

## Usage
- Services page: Grid of service categories
- Homepage: Featured services section
- Hover effect: Color changes to cyan (#00D4FF)

- [Heroicons](https://heroicons.com) - MIT license
